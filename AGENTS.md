# AGENTS.md

## Sobre o projeto

Clone do [TabNews](https://tabnews.com.br) desenvolvido para o [curso.dev](https://curso.dev), implementado com a ajuda de agentes de IA.

## Stack

- **Next.js** com **App Router** (diretório `app/`)
- **React**
- JavaScript

## Comandos

- `npm run dev` — servidor de desenvolvimento
- `npm run build` — build de produção
- `npm run start` — inicia o build de produção

## Convenções

- Interface e conteúdo em português do Brasil (pt-BR).
- Mensagens de commit em português.
